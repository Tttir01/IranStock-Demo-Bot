# IranStock-Demo-Bot

ربات حرفه‌ای Paper Trading / Demo برای بازار سرمایه ایران.

این پروژه در این مرحله فقط داده بازار را می‌خواند و معاملات را شبیه‌سازی می‌کند. هیچ سفارش واقعی به کارگزاری ارسال نمی‌شود.

ویژگی‌ها:
- لایه داده TSETMC با retry، timeout و تشخیص block
- تحلیل EMA9/EMA21، RSI، MACD، حجم و قدرت خرید حقیقی
- موتور امتیازدهی 0 تا 100
- حساب Paper با سرمایه مجازی
- ثبت معاملات و محاسبه سود/زیان و drawdown
- اجرای دوره‌ای در GitHub Actions
- تست‌های مستقل از اینترنت با داده ساختگی

دسترسی TSETMC ممکن است به IP، زمان و endpoint وابسته باشد. برنامه در صورت عدم دسترسی خطای واضح ثبت می‌کند و معامله‌ای انجام نمی‌دهد.

واحد قیمت داخلی تومان است؛ TSETMC در بسیاری از فیلدهای قیمت از ریال استفاده می‌کند و لایه داده تبدیل را انجام می‌دهد.
